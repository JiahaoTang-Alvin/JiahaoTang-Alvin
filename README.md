一个围绕菜谱理解、菜谱生成和语音做饭助手的 AI 产品。

- 将社交媒体菜谱视频解析为结构化图文菜谱

### Bio Blocks Studio

<p>
  <a href="https://github.com/JiahaoTang-Alvin/bio-blocks-studio" target="_blank">
    <img src="https://img.shields.io/badge/GitHub-Bio%20Blocks%20Studio-181717?style=for-the-badge&logo=github" />
  </a>
</p>

一个开源的模块化个人主页构建工具。

- 像搭积木一样，用可拖拽模块拼出个人主页
- 支持个人信息、项目、图片、视频、文本、链接和社交卡片
- 支持隐藏版本，例如求职版、社交版、活动版和合作版
- 支持不同版本下的多语言内容
- 提供 `/admin` 后台，用于编辑内容和调整布局
- 使用 Vercel Blob 存储配置和图片，不需要传统数据库

### 健康轻旅

一个以食物识别和营养分析为核心的小程序项目。

- 拍照识别食物
- 输出营养信息与评分
- 支持健康档案与目标管理
- 将 AI 能力与实际产品体验结合
